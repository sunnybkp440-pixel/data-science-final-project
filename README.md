# Comprehensive Data Science Project Report (Week 5)

Final report of the Virtual Data Science with Python Apprentice Internship (Yuva Intern). It integrates four earlier tasks on one dataset: Breast Cancer Wisconsin (Diagnostic), UCI ML Repository (via scikit-learn).

| Week | Topic | Script |
|------|-------|--------|
| 1 | Data cleaning and EDA | `analysis.py` |
| 2 | Visualization and storytelling | `week2_analysis.py` |
| 3 | Hypothesis testing | `week3_analysis.py` |
| 4 | Machine learning model | `week4_model.py` |

- `Week5_Final_Project_Report.docx` – the full report (executive summary, methods, results, recommendations, limitations)
- `report_fig*.png` – the figures used in the report

## Run
```
pip install pandas numpy matplotlib seaborn scikit-learn scipy
python analysis.py
python week2_analysis.py
python week3_analysis.py
python week4_model.py
```
(Create the folders `figs`, `w2figs`, `w3figs`, `w4figs` first, because the scripts save their charts there.)

This is a learning project, not a medical device.
